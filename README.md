# Arduino Audio Visualizer

An Arduino-based audio visualizer that processes real-time audio signals using Fast Fourier Transform (FFT) and displays frequency information on an 8×8 LED matrix. The system samples audio at approximately 4 kHz, performs a 16-point FFT, and analyzes four frequency bands to generate visual patterns.
